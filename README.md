# Portfolio Website | Mario Mendoza
Personal portfolio website to showcase my projects, technical skills, experience and professional background as a Software Developer.

## Technologies used
- HTML5
- Tailwind CSS
- JavaScript
- Vite

## Installation

Clone the repository:
```
- git clone https://github.com/marioswc/myportfolio.git
- cd /myportfolio
- npm install
- npm run dev
```
